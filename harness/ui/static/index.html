Welcome to dev-loop

Two clicks and this repo is wired up.

    What this does
    • Writes .dev-loop/config.yaml with sane defaults.
    • Adds .dev-loop/runs/ to .gitignore.
    • Installs a tiny hello-dev-loop replay scenario so you can hit "Try the demo run" and watch a full pass-through.

    Flow overview

    The orchestration is built from five pieces. Click any to edit.

    1. Task contract — agent restates the request as goal + success criteria.
      schema · playbook
    2. Implementation in disposable sandbox.
      playbook · schema
    3. Patch extraction & clean reapply.
    4. Validation through registered capabilities (Jenkins, deploy, E2E).
      capabilities
    5. Triage on failure → next action (modify code, ask more diagnostics, escalate).
      schema · playbook

    Loop policy, scenarios and runs dir live in config.
